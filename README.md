# Просто Таро: Telegram-бот

Telegram-бот, который предсказывает будущее в мемах. Пользователь вытягивает одну из 22 карт Старших арканов и получает шуточное предсказание на день, описывающее типичную жизненную ситуацию.

## Возможности
- Случайная карта дня с картинкой и предсказанием
- Inline-кнопки: «Получить карту», «Помощь», «О боте»
- 22 карты, колода будет пополняться

## Команды
- `/start`: приветствие и меню с кнопками
- `/card`: случайная карта с предсказанием и картинкой
- `/help`: список команд
- `/about`: о боте

## Технологии
- Python 3
- [aiogram 3](https://docs.aiogram.dev/): асинхронный фреймворк для Telegram-ботов
- python-dotenv: хранение токена в переменных окружения
- Render: хостинг (конфигурация в `render.yaml`)

## Установка и запуск
1. Клонировать репозиторий:
```
   git clone https://github.com/[твой-ник]/[название-репозитория].git
   cd [название-репозитория]
```
2. Установить зависимости:
```
   pip install -r requirements.txt
```
3. Создать бота у [@BotFather](https://t.me/BotFather) и получить токен.
4. Создать файл `.env` по образцу `.env.example` и вставить токен:
```
   BOT_TOKEN=your_token_here
```
5. Запустить:
```
   python main.py
```
